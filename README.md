# 🎃 쉬운 할로윈 타이핑 게임

초보자도 편하게 즐길 수 있도록 난이도를 낮춘 브라우저 타이핑 게임입니다.

## 실행 방법
1. 저장소의 파일을 모두 다운로드합니다.
2. `halloween_typing_game_easy.html` 파일을 Chrome, Edge 등 웹 브라우저에서 엽니다.
3. 시작 화면에서 캐릭터를 고른 뒤 게임을 시작합니다.

## 게임 기능
- 한글 단어는 기존보다 약 2배 느리게 진행됩니다.
- 영어 단어는 기존보다 약 3배 느리게 진행됩니다.
- 연속으로 5번 실수하면 게임이 종료됩니다.
- 정답을 맞히면 연속 실수 횟수가 0으로 초기화됩니다.
- 단어를 바닥에 놓치는 경우도 실수로 계산됩니다.
- 본인 사진, 정장 캐릭터, 마녀 캐릭터 중 선택할 수 있습니다.
- HTML 파일 하나에 HTML, CSS, JavaScript가 포함되어 있습니다.

## 파일 목록
- `halloween_typing_game_easy.html` — 게임 본체
- `gemini_me.png` — 본인 사진 캐릭터
- `Gemini_fantastic.png` — 정장 캐릭터
- `gemini_woman.png` — 마녀 캐릭터
- `README.md` — 프로젝트 설명 및 실행 방법

## 참고
캐릭터 이미지 3장은 HTML 파일과 같은 폴더에 있어야 합니다. Tailwind CSS와 일부 폰트/효과음 등 외부 리소스가 사용되는 경우 인터넷 연결이 필요할 수 있습니다.
